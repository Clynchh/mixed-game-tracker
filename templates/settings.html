Settings

This is a plain folder path — Mixed Games Tracker only reads .txt files inside it on an interval. It never touches the PokerStars client or process, so it's not a HUD and doesn't interact with the client while you play. Find yours in PokerStars: Settings → Hand History → Hand History Location.
Required for accurate results in stud/razz games. Hold'em and Omaha hands only ever show your own hole cards, so guessing "hero" by position works fine — but stud/razz hands show every player's up-cards each street, so without your exact username the tracker can misidentify another player at the table as you and get your net result completely wrong.

Re-read every hand

Normally the app skips hand history files it has already read, which keeps scanning fast. After an update that improves how hands are read, use this to go back over every file so hands imported earlier pick up the fix. Your tags and notes are kept — only the hand details are refreshed.
